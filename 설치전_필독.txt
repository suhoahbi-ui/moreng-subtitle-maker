MoReng Subtitle Maker 실행 전 필독
=================================

MoReng Subtitle Maker는 MP4/MP3 파일에서 오디오를 꺼내기 위해 ffmpeg가 필요합니다.
ffmpeg는 앱에 포함되어 있지 않습니다.

선택 1. 가장 쉬운 방법: run_windows.bat 실행
-------------------------------------------

run_windows.bat를 실행하면 ffmpeg 설치 여부를 자동으로 확인합니다.

ffmpeg가 이미 설치되어 있으면 바로 앱을 실행합니다.
ffmpeg가 없으면 아래 선택지가 나옵니다.

1. winget으로 ffmpeg 설치 후 계속
2. 다운로드 페이지 열기
3. 일단 앱 실행

보통은 1번을 선택하면 됩니다.

주의:
winget 설치가 끝나도 현재 명령창에는 PATH가 바로 반영되지 않을 수 있습니다.
그 경우 창을 닫고 run_windows.bat를 다시 실행해주세요.


선택 2. ffmpeg 설치 전용 파일 실행
--------------------------------

install_ffmpeg_then_run.bat를 실행하면 winget으로 ffmpeg 설치를 먼저 시도한 뒤 앱을 실행합니다.

winget이 없는 PC에서는 이 방식이 실패할 수 있습니다.
그 경우 선택 3의 수동 설치 방법을 사용하세요.


선택 3. 수동 설치: ffmpeg 파일을 앱 폴더에 넣기
--------------------------------------------

이 앱은 ffmpeg 실행 파일을 직접 포함하지 않습니다.
대신 사용자가 아래 공식 안내 페이지 또는 신뢰 가능한 Windows 빌드 페이지에서 직접 다운로드하도록 안내합니다.

이 방식을 쓰는 이유:

1. ffmpeg는 LGPL/GPL 라이선스 조건이 적용될 수 있어, 앱에 직접 포함해 배포하면 별도 라이선스 고지와 배포 조건 확인이 필요합니다.
2. 사용자가 공식/신뢰 가능한 페이지에서 직접 받으면 오래된 파일이나 변조된 파일을 함께 배포할 위험을 줄일 수 있습니다.
3. 보안 프로그램이 외부 exe 파일을 앱에 묶은 배포판을 의심하는 경우를 줄일 수 있습니다.
4. 사용자가 최신 Windows용 ffmpeg를 직접 선택해 설치할 수 있습니다.

다운로드 안내:

FFmpeg 공식 다운로드 페이지:
https://ffmpeg.org/download.html

Windows용 FFmpeg 빌드:
https://www.gyan.dev/ffmpeg/builds/

설치 순서:

1. 위 페이지에서 Windows용 FFmpeg 압축 파일을 다운로드합니다.

2. release essentials build를 받는 것을 권장합니다.

3. 압축을 풀고 bin 폴더 안에서 아래 두 파일을 찾습니다.

   ffmpeg.exe
   ffprobe.exe

4. 두 파일을 이 앱의 아래 폴더에 넣습니다.

   tools\ffmpeg\bin\

5. 그 다음 run_windows.bat를 실행합니다.


확인 방법
---------

앱 실행 전 PowerShell에서 아래 명령을 입력해도 됩니다.

ffmpeg -version
ffprobe -version

버전 정보가 나오면 ffmpeg가 정상 설치된 것입니다.


중요 안내
---------

영상/오디오 파일은 외부 서버에 업로드하지 않습니다.
음성 인식은 내 PC에서 로컬로 실행됩니다.
단, Gemini 번역 기능을 사용할 경우 SRT의 자막 텍스트는 Gemini API로 전송됩니다.
